# Galaxy Shutter Mute

[日本語](README.md) · English

An app for changing Galaxy camera shutter-sound settings. Use [Galaxy Shutter Mute Manager](https://github.com/OneUI-Mods/galaxy-shutter-mute-manager) for installation and permission setup.

## Requirements

Requires a Samsung Galaxy environment with the supported shutter-sound setting. Previous validation covers Android 9–16 / One UI 1–8.5; this README update does not add Android 17 validation. The setting may be unavailable depending on the device, region, and camera-app version.

## Installation and usage

1. Install the Manager from its [Releases](https://github.com/OneUI-Mods/galaxy-shutter-mute-manager/releases).
2. Start Shizuku and authorize the Manager.
3. Use the Manager to install Galaxy Shutter Mute and grant its required permissions.
4. Open Galaxy Shutter Mute and change the shutter-sound switch.

The app uses older compatibility settings to access the required system setting. New Android versions restrict ordinary installation of this APK, so install it through the Manager.

## Distribution and restoring sound

The app's downloads are in [Releases](https://github.com/OneUI-Mods/galaxy-shutter-mute/releases). Turn the switch ON to restore sound. If a change does not take effect, reopen the supported camera app and check again.
